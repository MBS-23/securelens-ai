SecureLens AI is not merely a vulnerability scanner.

4. Example: SQL Injection lesson

Imagine the user chooses:

Python → SQL Injection

The platform should teach:

Step 1 — What is SQL Injection?

Simple explanation:

SQL Injection occurs when untrusted input is incorporated into a SQL query in a way that changes the intended query structure.

Then show:

❌ Insecure coding
user_id = request.args["id"]

query = "SELECT * FROM users WHERE id=" + user_id

cursor.execute(query)

Then explain line by line.

request.args["id"]
        ↓
Untrusted user input
        ↓
String concatenation
        ↓
SQL statement
        ↓
Database interprets input as SQL

Then:

Why is this dangerous?

The developer learns the root cause, not just the vulnerability name.

5. Then show secure coding
user_id = request.args["id"]

query = "SELECT * FROM users WHERE id=%s"

cursor.execute(query, (user_id,))

Then explain:

User Input
    ↓
Parameter
    ↓
Database Driver
    ↓
SQL Structure remains separate

Now the student understands why parameterization works.
