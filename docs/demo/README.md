# Demo recording

`walkthrough.webm` (about 70 s) and `screenshots/` are a real recording of the
platform: a fresh database, the real API and scan worker, and the dashboard,
scanning the code in `examples/` (vulnerable-shop, then the retest demo's
before/after versions). Nothing is mocked; the captions at the bottom of the
video are the only overlay.

Regenerate on your machine with `scripts/demo.sh` (needs `scripts/setup-local.sh` first).
